# SvgToPng

**Free SVG to PNG converter**

Convert SVG files to PNG with accurate dimensions and no distortion.

SvgToPng is a simple browser-based tool for converting SVG graphics to PNG while preserving their original proportions and dimensions.

## Features

* Convert SVG files to PNG
* Upload multiple SVG files at once
* Preview all uploaded SVG files
* Download converted PNG files individually
* Download all converted files as a ZIP archive
* Paste SVG code directly into the editor
* Preview SVG code before conversion
* Download PNG files generated from SVG code
* Preserve SVG proportions and dimensions during conversion

## Why SvgToPng?

SVG-to-PNG conversion can sometimes produce distorted results when the original SVG dimensions or aspect ratio are not handled correctly.

SvgToPng is designed to avoid this problem, preserving the original dimensions and proportions during image generation so the resulting PNG does not appear stretched or squashed.

## Two ways to convert

### Upload SVG files

Upload one or multiple SVG files and preview them before converting. Converted PNGs can be downloaded individually or together as a ZIP file.

### Paste SVG code

Paste SVG markup directly into the tool to preview it and generate a PNG without having to create a separate SVG file first.

## Privacy

SvgToPng processes the SVG content directly in the browser. Files do not need to be uploaded to a server for conversion.
